# Smart Saline Bottle Monitoring System

IoT-based project for monitoring saline bottle levels in hospitals using sensors and real-time alerts.

## Technologies Used
- Arduino IDE
- NodeMCU
- Ultrasonic Sensor
- Embedded Systems
- Web Server

## Features
- Real-time saline level monitoring
- Automatic alert system
- Reduced manual monitoring
- Sensor-based tracking

## Project Outcome
Improved monitoring efficiency through automated saline level detection and notifications.
